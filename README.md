# Buzon-Sugerencias

Taller De Programación Aplicada 

Backend construido con Node.js y Express para recibir, guardar y mostrar sugerencias enviadas por los usuarios sobre las instalaciones de la institución. El servidor guarda las sugerencias en memoria mientras está activo y expone un panel de administración para verlas listadas.



Historias de Ususario

Como usuario de la biblioteca 
Quiero enviar una sugerencia sobre la biblioteca 
Para que el tesorero la revise

como personal de la cafeteria
quiero enviar una sugerencia sobre los alimentos
para que almacen lo revise

Como usuario de la cafeteria 
quiero enviar una queja sobre la comida
para que administracion la revise

Casos de prueba
| Enviar sugerencia completa      | Se guarda y limpia el form  |  Si  |
| Enviar con mensaje vacío        | El servidor no la guarda    |  Si   |
| Ver panel de administración     | Aparece la lista completa   |  Si   |
| Visitar una ruta inexistente    | Devuelve error 404 en JSON  |  Si   |
